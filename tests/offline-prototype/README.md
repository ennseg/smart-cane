# Автономный тест умной трости на ESP32

Проект PlatformIO для проверки собранной трости на столе. Один лазерный дальномер GY-530 измеряет расстояние, вибромотор передаёт его ритмом, а удержание кнопки SOS выводит событие в последовательный порт. Для запуска достаточно ESP32, подключённых узлов и USB-кабеля с передачей данных. Токены, Wi-Fi и запущенный сервер для этой сборки не требуются.

**[Сборка и подключение по шагам](ASSEMBLY.md)** — две монтажные платы, распиновка, пайка 2N7000, питание мотора, разбор прошивки и диагностика пропадающего контакта.

[Задачи по сборке и испытаниям](TASKS.md)

## Загрузка за три шага

1. В VS Code с расширением PlatformIO открой папку **`tests/offline-prototype`**, в которой лежит этот README и [platformio.ini](platformio.ini).
2. Подключи ESP32 DevKit V1 по USB. Если плата питается через USB, отключи внешний плюс 5 В от её VIN. Для отдельного источника мотора соедини его минус с GND ESP32.
3. Выбери **PlatformIO → Project Tasks → esp32doit-devkit-v1 → Upload and Monitor**. Скорость монитора — **115200 бод**. Кнопка EN/RESET позволяет снова увидеть начало журнала.

Через терминал PlatformIO, из папки этого проекта:

```sh
pio run
pio run -t upload
pio device monitor -b 115200
```

## Что проверить

| Действие | Ожидаемый результат |
|---|---|
| Перезапустить ESP32 | В мониторе появляются `Тест: один GY-530, вибромотор и кнопка SOS.` и при успешном запуске `GY-530: датчик готов` |
| Держать плоскую коробку перед датчиком примерно в метре | Строки вида `Расстояние: 100.0 см`. Мотор включается примерно дважды в секунду |
| Подвинуть коробку на 20–30 см | При свежем достоверном показании до 30 см включительно мотор работает непрерывно |
| Убрать коробку | При 200 см и дальше мотор выключен. При отсутствии достоверного измерения он также выключен, а причина видна в мониторе |
| Удерживать SOS две секунды | Один раз появляется `SOS: кнопка удержана 2 с`. Включается индикатор GPIO2. После отпускания индикатор гаснет |

**Подключение для этой сборки.** GY-530 использует SDA → GPIO21, SCL → GPIO22 и XSHUT → GPIO18. Вывод GPIO27 управляет затвором ключа мотора. Кнопка замыкает GPIO13 на GND. При наличии установленного GPS его UART в этом тесте не опрашивается. Запуск режима четырёх датчиков закомментирован в [main.cpp](src/main.cpp).

Для проверки цепи без ESP32 нужны схема питания конкретной сборки и допустимое напряжение мотора. В прототипе использован мотор 1020 на 3 В с рабочим диапазоном 1,5–3,7 В. Расположение диода и обеих точек подключения мотора показано в [руководстве](ASSEMBLY.md#motor).
