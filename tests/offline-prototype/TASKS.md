# Задачи по умной трости

- [ ] Закрепить провод кнопки SOS на D13 (GPIO13) ESP32. Проверить, что при удержании кнопки две секунды в мониторе порта появляется сообщение SOS.
- [ ] Сделать надёжные соединения GPS-модуля и дальномеров GY-530 с выводами ESP32 по [схеме подключения](ASSEMBLY.md). Закрепить провода у разъёмов.
- [ ] Протестировать все четыре дальномера вместе. По очереди подносить препятствие к каждому и сверять его показания с номером канала в мониторе порта.
- [ ] Протестировать трость в полной сборке по Wi-Fi. Проверить получение координат GPS, реакцию мотора на препятствие и доставку SOS через сервер в Telegram.
- [ ] Перенести систему питания на монтажную плату. После переноса проверить включение и выключение собранной трости.
- [ ] Разработать корпус и подобрать трость для крепления корпуса и датчиков.
- [ ] Установить и подключить SIM800L. Проверить передачу данных при отключённом Wi-Fi.
