# Прошивка умной трости

Проект PlatformIO для DOIT ESP32 DevKit V1 (Arduino). Текущая версия выводит расстояние с одного GY-530 в Serial Monitor, обрабатывает кнопку SOS и отправляет телеметрию по Wi-Fi. Режим четырёх датчиков с вибромотором сохранён в `src/obstacles`, его запуск закомментирован в `src/main.cpp`.

## Сборка и запуск

1. Открой папку `firmware` в PlatformIO.
2. Скопируй `include/secrets.example.h` в `include/secrets.h`. В PowerShell из папки проекта выполни `Copy-Item include/secrets.example.h include/secrets.h`.
3. Для отправки телеметрии укажи в копии свою сеть Wi-Fi, адрес сервера, идентификатор устройства, токен и ключ HMAC. Адрес из шаблона приведён для примера. Порядок регистрации устройства описан в [документации сервера](../server/README.md). Для проверки только дальномера достаточно скопировать шаблон.
4. Выполни `pio run` для сборки. При подключённой по USB плате выполни `pio run -t upload`, затем `pio device monitor`. Скорость порта — 115200 бод.

Для одного GY-530 прошивка использует GPIO21 для SDA, GPIO22 для SCL и GPIO18 для XSHUT. Кнопка SOS подключается между GPIO13 и GND. В тестовом режиме выход вибромотора GPIO27 удерживается в низком уровне.
